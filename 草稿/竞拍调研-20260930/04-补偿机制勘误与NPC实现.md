# 补偿机制勘误与 NPC 实现

## 对早期调研的纠正

早期笔记只提到了收益/奖励栏，漏记了“中拍收益为负时，其他三位分别获得 10% 奖金”的明确机制。该缺项已补入项目结算及规则说明。实现解释为按成交价超过拍品真实价值的差额计奖。

来源：异环官方 Steam「即刻落槌」公告：
https://steamcommunity.com/games/4508340/announcements/detail/680757319885128276?l=schinese

正文备份：`artifacts/auction-v3/nte-official-guide.txt`；原始 HTML：`nte-official-guide.html`。完整正文来自 HTML 的 `data-partnereventstore` 数据，不只依赖页面摘要。另有社区机制参考 `https://www.ntestation.com/即刻落槌`，官方公告优先。

原作采用专用拍卖货币「金贝铢」；当前项目采用街机共享钱包，因此原作参数照搬到 PvE 并不自动平衡。官方还描述了收藏展出的时间收益，当前项目只实现展柜展示，没有实现挂机产出。

例：真值 1,000、成交 1,500，赢家亏 500，其他三人各得 50，合计补偿 150；四方总价值净变化为 -350。赢家自身亏损仍为 500，并非 350。机制缓和未中拍者的损失感，但不是防恶意抬价或保本保证。NPC 的亏损不等于真实玩家货币销毁，所以 PvE 的补偿必须单独审计。

**项目自定义限额**：单箱 40、玩家 UTC+8 每日 60，跨场/会场共用。此处限额不是在引用异环原作参数。社区所述 30% 特殊效果没有接入当前版本。

## 本地交付与验证

- 六类动机、私有估值、预算上限、真实技能与仪器、三箱连续钱包/收藏/记忆，见 `arcade/AUCTION.md`。
- NPC 从玩家未选择的固定主播抽取，不另造主播。
- UI 展示对手倾向和公开动作，不泄露其私有估值和本轮报价。
- 最新收益数据、计算口径和未解决的下限策略增值，见 `arcade/AUCTION-ECONOMY.md`。旧经济报告不可当作新模型结果。
- 正常策略也存在亏损，免费下限策略低档场资金增长仍快，尚未宣布经济平衡完成。
