## NPC：目标不同，而非只换一个出价随机数

三位对手从未被玩家选作搭档的固定主播中无放回抽取，本场内不更换，下一场重新抽取。**主播身份决定技能；本场随机生成的倾向决定竞拍动机。** 同一主播下一场可能换一种打法，避免把真人主播固定成某种负面性格。

| 倾向 | 主要动机 | 追价条件 | 收手条件 |
| --- | --- | --- | --- |
| 收藏补全 | 找到偏爱系列里尚未拥有的藏品 | 私有候选中有缺藏时允许有限溢价，确认缺藏后更积极 | 重复藏品没有收藏溢价；预算、估值和可接受损失同时限价 |
| 保守捡漏 | 出售赚钱、留出利润空间 | 情报表明有差价时才提高报价 | 历史价格超过承受区间时明确退出，不追沉没成本 |
| 品类行家 | 熟悉门类中争取优势 | 对专长门类更有偏好，优先考虑类别检索 | 跨品类增加利润/风险缓冲；同样保留现金 |
| 稳健估值 | 提高鉴定把握后成交 | 高不确定性时优先补情报 | 情报不足会保守观察；过热就撤 |
| 冒险押宝 | 接受不确定性、押较好品质 | 更愿意提前报价，愿接受较薄利润 | 仍有现金和最大承受损失上限，不使用无限资金 |
| 试探博弈 | 看历史报价，择机抢拍 | 在自己愿意买入的区间内施压、尝试提前落槌 | 抬价仍可能自己中拍；不做无风险假报价，不根据本轮玩家报价改价 |

每场随机化耐心、自信、准确度、现金留存比例、损失承受度、利润需求、偏好溢价、仓位上限、试探概率、偏爱系列和已有收藏。每箱生成稳定的判断误差、紧迫感和使用仪器的机会倾向；不是每帧重掷估值。

### 行为树 / 黑板

实现形式为**代码式优先级选择器 + 条件节点**，而不是可视化树编辑器。黑板分成对手私有情报、历史公开信息、自身钱包与收藏、局内记忆四部分。

```text
根节点：本轮决策
├─ 不具备参与资格 → 无动作（退出或不在加赛名单）
├─ 私有情报策略
│  ├─ 开箱：按主播真实技能获取限定数量的信息
│  ├─ 仪器已消耗 / 结果冗余 → 保留
│  ├─ 专长查询 / 估值不确定 / 历史价格压力 / 耐心期限 → 使用仪器
│  └─ 否则等待
├─ 可用现金不足 → 退出
├─ 对兼容候选做概率估值
│  └─ 均值、方差、上下界、缺藏价值、熟悉类别价值
├─ 自身硬限制
│  ├─ 目标利润 + 风险折扣 + 有限偏好溢价
│  ├─ 现金留存 + 仓位上限
│  └─ 可接受损失 + 连续亏损降温
├─ 历史竞争明显过热 → 按倾向退出
├─ 仅自己还在场 → 保留议价空间
├─ 早期情报不足且有耐心 → 小额观察
├─ 常规价值报价
├─ 试探型条件满足 → 上限以内小幅施压
├─ 预测旧价 × 本轮提前成交倍率仍在上限内 → 尝试抢拍
└─ 人类式整价尾数 → 最终限价 → 提交密封报价
```

仪器与技能已重做：11个主播具有11种不同的信息时序，详见 `AUCTION-INSTRUMENTS.md`。NPC在每箱开始前以至多当前资金12%的采购预算补货，持有库存跨箱保留，不免费重置。三槽配装按动机与资产档次选择；每轮比较不确定性、历史热度、预期信息收益和消耗成本，同款每箱至多一次，单轮至多一件。昂贵仪器不是默认必用，剩余库存继续占用采购资金。

仪器随机揭示或规则性选择由共同情报分发器执行，NPC规划器只接收自己的观察；“最大占格”“最高品质”等选择权是仪器本身的明示效果，不是AI偷看后挑选。数量、总额、均价进入估值；占格统计收紧安全上下界。统计条件交叉时使用近似估计与保守上下界，不宣称实现了所有可能的组合逆算。

### 核心约束

令 `M` 为自身估值，`P` 为收藏/品类偏好溢价，`σ` 为不确定性：

- 意愿价：`(M × (1 - 利润需求) + P - σ × 风险系数 × (1.5 - 自信)) × 连亏降温`。
- 估值硬上限：`min(候选最高价值 × 1.22, M + min(P + M × 0.10, 自身现金 × 损失承受度))`。
- 现金硬上限：`min(现金 - 留存现金, 现金 × 仓位比例)`。
- 实际报价始终不超过这三种上限；随机波动、博弈施压和抢拍也不例外。
- 下限、均值和真实价值是不同概念；NPC 有合理估错的可能，并非保证每次赚钱。
- 收藏型支付真实成交价并把目标缺藏留下，其他物件出售；持有藏品占用流动资金。收益记忆区分藏品价值盈亏和现金变化。
- 连续亏损后降温；箱末揭晓后轻微修正下一箱的估值偏差与市场热度。跨场长期人格/钱包暂未实现。

### 公平性边界

- NPC 估值模块只收到轮廓、占格、其私有品质/类别/鉴定结果、过去轮次公开报价。
- 三位 NPC 先完成报价，随后才公开本轮玩家报价、变更退场名单。
- 玩家仪器结果不进入 NPC 黑板；NPC 仪器结果也不改变玩家私有已鉴定标记。
- 第1/3轮少量轮廓公开是共享事件；第三轮不再自动公开所有品质。
- 仓库、公共情报、玩家私有情报、NPC RNG 分离：多用一次仪器或多走一次随机分支不会改掉下一箱物品。
- 正常 UI 只展示固定主播身份、提交状态、公开报价与自然气泡；倾向、偏好系列、私有技能/仪器情况、钱包和真实报价上限不作为席位文案展示。
- `export()` / 开发追踪可读取完整状态，用于存档和测试。纯本地游戏不是反作弊服务器；本地存档、客户端时钟可被修改。

## 规则与经济

四人同步暗拍，1–4 轮提前成交倍率为 2 / 1.6 / 1.3 / 1.1，要求严格大于。第 5 轮唯一最高价成交，第 6 轮仅并列最高者加赛；仍并列则流拍。退出本箱后旧价失效。无倒计时，等待手动出价或放弃。每场一箱，逐件揭晓后出售或留藏，回准备页。

`compensation = floor(max(0, 成交价 - 真实价值) × 10%)`，其他三个席位分别计算，不是三个席位共分 10%。赢家仍承担全部亏损。

本项目额外节流（不是原作参数）：**单箱 40、玩家 UTC+8 每日 60，跨会场与场次共享**；NPC 会话内补偿也受上限约束。无成交、本人中拍无补偿。配置在 `AuctionData.economy`。规则 UI 明示限额。

`closeLot(choice, balance?, {compensationLimit})`：调用方负责账户级每日剩余额度；独立引擎不保存跨场账号。网页在钱包锁内读取最新额度，结合交易日志一次性更新钱包、引擎余额、收据和额度。浏览器支持 Web Locks 时处理双页并发；不支持时仅保证单页事务。离线时钟回拨不重置当前已记录日期，但这不是服务端防刷。

**3.2成本口径**：采购立即扣现金，使用减库存且不再次扣现金。结果页的净价值盈亏减去本箱已消耗仪器成本，未中拍也承担成本；未消耗库存以购入成本记为工具资产，而非可回收现金。没有免费全品质仪器，安全下限报价仍可能因为耗材亏净值。高档工具并不保证性价比，最新模拟、尾部风险与待调参数见 `AUCTION-ECONOMY.md`；不宣称已经取得真人长期平衡。

购买、使用、报价、下一箱和结算均走同一锁与write-ahead日志。库存、私有扫描结果、会话预算与收据同步落盘；普通保存有修订号检查并使用同一锁，防止旧窗口覆盖新库存。Web Locks缺失时仍是单页回退，不保证跨窗口互斥。

### 结算字阶、推荐出价与文案核对（2026-09-30）
- 结算沿用同一横屏画布：净盈亏36、拍品总值32、成交价24、标题22、已用仪器/门票/补偿金额18、标签14（逻辑像素）。费用用横向次级行，净盈亏独立分区。保留逐件开箱、计价和跳过全开。
- NPC 首位等待由1.8–4.5秒调整为1.4–3.6秒；后续每位间隔由1.4–4.8秒调整为1.1–3.9秒。随机座位顺序不变；全员提交后仍停留0.85秒，回合结果仍展示3.3秒后自动继续。旧存档中的进行中演出按原时间完成。
- `auction-recommendation.js` 是纯函数，只接收玩家可见视图及当前余额。按公开会场品质权重/该品质目录件数加权候选价格，累加均值与方差；以现有统计情报约束的价值上下限收紧均值。预留0.35倍标准差（不低于已知下限）后再留12%余量，扣除本场门票和已消耗仪器成本，限于钱包余额，再向下取整（百位以上5、千位以上10）。成本用于净价值计算，不再次扣现金。
- 这是保守的近似估算，不是最优策略或盈利承诺；没有精确拟合装箱筛选或所有统计信息的联合后验，不读取真实隐藏藏品、对手私有信息或本轮密封报价，不推进任何随机数状态。无正数建议时提示退出，不强行建议1元。推荐按钮只填写数字，数字键盘、00、上次报价×1.3和最终确认继续独立工作。
- 已逐项核对11位搭档和43种仪器的效果说明：触发轮次、随机/指定目标、揭示数量、轮廓与品质区别、均价取整、空目标及并列目标处理。删去技能主观点评、会场宣传句、空收藏抒情句；统计情报增加品质/类别主体。NPC气泡台词保留。
