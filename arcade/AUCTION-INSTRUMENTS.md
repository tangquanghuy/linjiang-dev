# 3.2 · 主播技能与付费仪器

## 核心变化

- 11位固定主播，11条不同技能时间表；8种已查社区原机制、1种社区预览改编、2种项目原创组合。
- 43种仪器，入门/进阶/专业/高级/超级/至尊6档，三槽自选，不要求用满。
- 采购立即扣钱包；使用减1库存；未使用跨场保留。每轮最多1件，同款每箱最多1件。
- 库存初始为0，选中仪器不等于已购买。旧版免费仪器不兑换赠品。
- 结果页扣除实际消耗成本；不在成交结算再次扣采购款。
- 下表**全部是本项目售价与缩放数量**，不是异环原作价格。原页面17套仪器组/9个角色逐项记录在调研目录05号文档。

## 原机制适配边界

本地每箱6–8件、6×6储物格，因此微/小/中/高/超级的品质数量为1/2/3/4/5，轮廓为2/3/4/5/6，身份鉴定为1/2/3/4/5。原页面记录是品质2/4/6/8/10、轮廓4/6/8/10/12、身份1/2/3/5/6。最高档特殊效果有机会更精准，但固定价格与低价值仓库并不匹配，玩家应按箱子预期价值采购，而非无条件选贵的。

全仓数量在本项目仍是公开信息，统计仪只提供尚未知的品质/类别数量、均价、总额与占格。品质不等于轮廓；位置未知的品质标记显示在独立条目中。最高品质/最大占格选取同档并列时按仓库slot顺序确定，不偷偷挑同品质最贵物体。

专项仪无待辨认目标时，返回该类件数并消耗；重复信息返回失败但不扣库存，不用免费失败来探测隐藏类别。至尊仪要求目标完全没有任何信息，已有轮廓/品质/类别的物体不算目标。

## NPC决策

同一组效果给所有席位使用，技能按回合触发；NPC看不到玩家私有结果与当前报价。每箱采购至多可用现金12%，按动机与资金选择三类工具，未用库存保留；仪器预期收益不足、价格已过热、库存不足、同款本箱已用时放弃。资金预算在购买时扣除，之后出价基于剩余资金。库存与消耗记录包含在可恢复快照。

## 交易约束

网页分别使用purchase随机事务ID、consume-箱ID-回合、bid-箱ID-回合、next-箱ID和结算箱ID。一个相同回合的跨窗口重复消耗只提交一次。购买/消耗的write-ahead日志中同时包含库存、钱包后值、私有情报快照与收据，恢复时不只恢复钱而丢弃技能效果。普通状态保存同样取锁并核对修订号。无Web Locks浏览器仅保证单页串行，纯本地存档不是联网反作弊。

## 成本例子

准备阶段买微型鉴定仪花30，钱包1000→970；本箱使用后库存1→0，钱包仍970。以400拍到价值450的仓库并出售，现金970→1020。本箱拍卖赚50、耗材成本30、净值赚20。若未拍到且没有补偿，现金不会再扣钱，但已消耗仪器导致净值亏30。购买后未使用则仍持有30账面工具资产，不当作30现金，也不直接全部算成本。

## 验证

`npm run auction:instruments` 检查43效果、11种时间轨迹、真实价值上下界、同轮/同款限制与RNG隔离。
`npm run auction:purchases` 检查购买持久化、双页采购/使用、余额不足并发、购买与消耗日志两处中断恢复。
模拟器`npm run auction:sim -- --accounts 100 --horizon 12 --label paid-final` 记录净ROI、现金余额、未消耗工具账面价值、NPC采购成本及低于会场门槛的比例。
